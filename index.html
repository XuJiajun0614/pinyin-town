🟠 第四站:声调擂台

📖 拼音还有四个声调小帽子:
一声平(—)、二声扬(／)、三声拐弯(∨)、四声降(＼)。
📖 标调规则小口诀:
四个声调四顶帽，六个单韵母抢着要 —— a o e i u ü
有 a 在，把帽戴；
a 不在，o e 戴；
要是 i u 在一起，谁在后面给谁戴。
例:huā(戴在a) · shǒu(戴在o) · niú(戴在u)

✨ 第五站:魔法拼写屋

📖 拼音里有几个淘气的小魔法,记住它们:
① j q x 真稀奇，见了 a 和 ao，需要 i 联系:
  j + ia = jia　q + ia = qia　x + ia = xia
  j + iao = jiao　q + iao = qiao　x + iao = xiao
② j q x y 真淘气，从不和 u 在一起。
③ ü 见了 j q x 和 y，摘掉帽子行个礼:
  jü→ju　qü→qu　xü→xu　yü→yu
④ n、l 见到 ü，一定不能摘帽子:
  n + ü = nü(女)　l + ü = lü(绿)
